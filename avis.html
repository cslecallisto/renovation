Les robinets thermostatiques, pour les curieux

Un robinet thermostatique règle la chaleur radiateur par radiateur, pièce par pièce.

Pour les curieux : sur beaucoup de modèles, la tête peut plus tard être remplacée par une tête connectée, pilotée par une sonde de température. Le modèle n’est pas choisi : ce point reste à voir avec le maître d’œuvre.
